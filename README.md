# Painel de Desenvolvimento Pessoal

Este projeto é uma aplicação web minimalista desenvolvida para centralizar e organizar a rotina de desenvolvimento pessoal e produtividade. O painel permite acompanhar hábitos diários, gerenciar pequenas tarefas, definir metas, registrar gratidões e escrever reflexões em um só lugar, oferecendo acompanhamento visual de progresso por meio de barras e indicadores de porcentagem. Desenvolvido com HTML5, CSS3 e JavaScript puro como Projeto Integrador da disciplina de Desenvolvimento Front-end para Web.
